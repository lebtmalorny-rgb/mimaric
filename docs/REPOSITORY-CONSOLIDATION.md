содержимое доставленных YAML-сборщиков или содержимое post-fence патча.

## Что убрано из актуального дерева

- Старые repair-0509, standalone Mistral hotfixes, stage1 и service-role пакеты:
  не использовать их как дополнительные исправления уже обновлённой базы 0809.
- Старый `collect.yml`: актуальный автономный файл называется `collect-v2.yml`.
- Дубли верхнеуровневых установочных инструкций, отдельные вырезки Ansible-ролей,
  `boofer`, снимки экранов, кэши Python и временные планы.
- Экспериментальные planned-return-v2 / planned-return-kit не входят в текущую
  поставку. Их коммиты и локальные изменения сохранены в приватном backup.

Старые патчи внутри `horizon/` намеренно сохранены: это необходимые зависимости
отдельного Horizon-комплекта с его собственной базой, а не повторный набор для 0809.
NTP patch и его guide также сохранены внутри этого исходного комплекта.

## История и восстановление

Перед изменениями создан полный приватный backup рабочего каталога и Git bundle
в соседнем `analysis/cleanup-backups/mimaric-consolidation-20260910.jPXP8L/`.
В backup есть также независимые исходные репозитории компонентов и незакоммиченные
правки. Его нельзя публиковать: он содержит рабочие данные, не прошедшие отбор.

Истории обычных объединяемых веток сохраняются предками итогового main; в текущее
дерево перенесены выбранные актуальные файлы, а не сумма всех вариантов.
История retired planned-return kit хранится отдельно в backup, не включается
обратно в активный комплект. Исходные ZIP 0809 вне репозитория не удаляются.

Проверки этой реорганизации — локальные: состав и хеши, автономность/тесты
сборщиков, Markdown-ссылки, синтаксис Ansible и наложение Masakari-патча на
свежую копию его 0809. Они не заменяют приёмку образов и сценариев на стенде.
