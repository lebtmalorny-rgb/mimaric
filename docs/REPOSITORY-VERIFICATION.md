Итого 105 разных тестов в перечисленных выбранных наборах. Пересекающиеся
повторные прогоны не суммируются. Тесты Mistral failure paths проверяли 504,
ошибку аутентификации и несовпадение имени узла; каждый сценарий создавал один
приватный TXT без тестовых секретов. PowerOps fixtures проверяли сохранение
результатов доступного узла при недоступном другом, включая пустые списки ВМ.

Первый parser-прогон выявил отсутствие python-mistralclient в временном venv.
Установлен только `python-mistralclient==5.4.0` (`--no-deps`), версия взята из
переданного kolla-pvs constraints; повторный прогон прошёл. Образы не менялись.
Loopback HTTP test потребовал разрешения локального socket bind вне sandbox.

Перед изменениями проверены Git bundle и 61 004 файла полной локальной резервной
копии. Незакоммиченные изменения не включались автоматически в публикацию:
выбранные тесты/документы перенесены, остальные сохранены в backup.

Не выполнялись новый полный unit-прогон Masakari/Mistral, полный Django/Horizon
прогон, сборка образов, deploy/reconfigure и live acceptance. Сохранение Horizon
не является доказательством его совместимости с 0809. Исторические результаты
в перенесённых документах не переобозначены как результаты этой проверки.
