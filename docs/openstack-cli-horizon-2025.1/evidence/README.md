# Исходники, подтверждающие анализ

Здесь сохранены только файлы, на которые ссылается [отчёт](../README.md). Они скопированы без изменений из проверенных источников. Это материал статического анализа, а не пакет для установки или запуска сервисов.

[Manifest](https://github.com/lebtmalorny-rgb/mimaric/blob/89be5492cba1a1c44d187a7f1df4a4b2243e1ab1/docs/openstack-cli-horizon-2025.1/evidence/manifest.json) содержит исходные пути исследования, коммиты или ссылку на архивную базу и SHA256 каждого файла. Архивные базы и их SHA256 перечислены в [данных исследования](https://github.com/lebtmalorny-rgb/mimaric/blob/89be5492cba1a1c44d187a7f1df4a4b2243e1ab1/docs/openstack-cli-horizon-2025.1/data/local-source-manifest.json). Upstream-код не дублируется: ссылки отчёта указывают на теги OpenStack.
