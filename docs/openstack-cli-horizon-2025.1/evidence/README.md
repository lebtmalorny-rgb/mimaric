# Исходники, подтверждающие анализ

Здесь сохранены только файлы, на которые ссылается [отчёт](../README.md). Они скопированы без изменений из проверенных источников. Это материал статического анализа, а не пакет для установки или запуска сервисов.

[Manifest](manifest.json) содержит исходные пути исследования, коммиты или ссылку на архивную базу и SHA256 каждого файла. Архивные базы и их SHA256 перечислены в [данных исследования](../data/local-source-manifest.json). Upstream-код не дублируется: ссылки отчёта указывают на теги OpenStack.
