# Horizon PowerOps — сохранённый отдельный комплект

Перенесён из локальной ветки `powerops/horizon-clean-v2`, commit
`6f14ecdcaf4012eb1637f58c0ab88ec176c4adc4`, при объединении в `mimaric/main`.
Исходники плагина, 36 зависимых патчей, тесты и исходные документы сохранены.
Имя прежней ветки с `v2` относится к Horizon, а не к удалённому planned-return-v2.

**Не применять этот набор поверх 0809 без отдельной проверки совместимости.**
Horizon-комплект зафиксирован на более ранних точных исходных базах и включает
собственный backend/RBAC-контракт. Сам перенос файлов не включает панель,
не обновляет Mistral и не подтверждает совместимость с работающим стендом.

- [Операции Horizon](POWEROPS_HORIZON_OPERATIONS.md).

- [Исходные результаты поставки](DELIVERY.md) — исторические результаты,
  не новый прогон на 0809.

Команды ниже выполнять из каталога `horizon/`:

```bash
python3 -m unittest tests.test_delivery_artifacts tests.test_horizon_backend_baselines -v
shasum -a 256 -c SHA256SUMS
```

Полные cross-repository тесты требуют отдельных исходных деревьев, указанных
в переменных `POWEROPS_*_TREE`; они не должны незаметно подменяться базой 0809.
Тесты Django/плагина требуют подготовленного Horizon-окружения.
Планы и evidence внутри этого каталога сохранены как часть исходного комплекта,
а не как текущие задания к выполнению.
